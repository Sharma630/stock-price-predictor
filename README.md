# Stock Market Index Movement Forecasting Using Multiple Indicators and Deep Learning

An end-to-end, runnable B.Tech final-year project that forecasts the
next-period movement of major Indian stock market indices — **NIFTY 50**
and **S&P BSE SENSEX** — by combining classical technical indicators
(Moving Averages, MACD, RSI) with an LSTM deep-learning model.

> **Disclaimer:** Predictions generated by this system are for educational
> and research purposes only and should not be considered financial or
> investment advice.

## Overview

The application downloads historical OHLCV data, cleans it, computes
technical indicators, trains an LSTM on multivariate sliding-window
sequences, and serves everything through an interactive Streamlit
dashboard — all runnable locally on a CPU-only Windows laptop, with no
paid APIs or API keys required.

## Features

- Live historical data via `yfinance` (NIFTY 50 `^NSEI`, SENSEX `^BSESN`),
  with a bundled sample-data fallback if live download fails.
- SMA(20, 50), EMA(12, 26), MACD(12, 26, 9), RSI(14), plus optional
  volatility/momentum features.
- Interactive Plotly charts: candlestick, moving-average overlay, MACD,
  RSI, actual-vs-predicted.
- A 2-layer LSTM network with dropout, trained on 60-day multivariate
  sequences (all hyperparameters configurable in the UI).
- Ticker-specific model persistence — no need to retrain on every restart.
- Full evaluation suite: MAE, RMSE, MAPE, R², Directional Accuracy.
- Next-step forecast with UP / DOWN / NEUTRAL classification, plus an
  experimental multi-day (1/3/5-day) recursive forecast.
- Automated tests for indicators, preprocessing, and sequence generation.

## Installation

### Windows Quick Start

1. Install **Python 3.10 or 3.11** from [python.org](https://www.python.org/downloads/)
   (check "Add Python to PATH" during installation).
2. Extract the project ZIP.
3. Open the folder in **VS Code**.
4. Open a terminal (`` Ctrl+` ``) and run:
   ```
   setup.bat
   ```
5. Start the app:
   ```
   run.bat
   ```
6. Open your browser to **http://localhost:8501**.

### VS Code Setup (Manual / Cross-Platform)

```
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

python -m pip install --upgrade pip
pip install -r requirements.txt
```

## How to Run

```
streamlit run app.py
```
Then open **http://localhost:8501** in your browser.

## How to Train the Model

1. Open the **Model Training** page in the sidebar.
2. Review the dataset overview (rows, train/val/test sample counts).
3. Adjust lookback / epochs / batch size if desired.
4. Press **TRAIN MODEL**. Training runs on CPU and is capped to a
   lightweight default epoch count for a fast classroom demo; increase
   epochs for a more thorough final run.
5. On completion, the model, scaler, and metadata are saved under
   `models/` using ticker-specific filenames (e.g. `NIFTY50_lstm.keras`).

## How to Generate a Prediction

1. Open the **Forecasting** page (requires a trained model for the
   selected index).
2. Press **GENERATE FORECAST** to see the next-period Predicted Close,
   Expected Change, and UP/DOWN/NEUTRAL direction.
3. Review the experimental multi-day (1/3/5-day) forecast, clearly labeled
   as experimental with increasing uncertainty per step.

## Technical Indicators

| Indicator | Formula / Definition |
|---|---|
| SMA(20), SMA(50) | Simple moving average of Close over N periods |
| EMA(12), EMA(26) | Exponentially weighted moving average of Close |
| MACD | EMA(12) − EMA(26) |
| MACD Signal | EMA(MACD, 9) |
| MACD Histogram | MACD − Signal |
| RSI(14) | 100 − 100 / (1 + RS), RS = avg gain / avg loss (Wilder smoothing) |

## LSTM Architecture

```
Input(lookback=60, features=13)
-> LSTM(64, return_sequences=True) -> Dropout(0.2)
-> LSTM(32) -> Dropout(0.2)
-> Dense(16, relu) -> Dense(1)
```
Optimizer: Adam · Loss: MSE · Metric: MAE · Callbacks: EarlyStopping,
ReduceLROnPlateau.

## Model Evaluation

Reported on a held-out, strictly chronological test set:
- **MAE** — average absolute error in index points.
- **RMSE** — penalizes larger errors more heavily.
- **MAPE** — average percentage error.
- **R²** — variance explained by the model.
- **Directional Accuracy** — % of correct UP/DOWN calls.

## Limitations

- Market prices are noisy; technical indicators are lagging transformations
  of past prices.
- Macroeconomic and sentiment factors are not represented in OHLCV data.
- LSTM output is probabilistic/approximate — historical accuracy does not
  guarantee future performance.
- Recursive multi-step forecasts accumulate error with each additional day.
